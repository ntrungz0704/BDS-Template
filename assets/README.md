# Assets Directory (Việc 3)

> Thư mục này dùng để chứa hình ảnh mẫu chuẩn phục vụ quá trình hiển thị dữ liệu giả lập cho 3 Tenant mẫu (Hoàng Gia Land, Zen Homes, Apex Realty) trên VPS và Local.

## 📁 Cấu trúc thư mục Assets

```
assets/
├── logos/     # Chứa ảnh logo của các công ty (Hoàng Gia, Zen, Apex)
├── projects/  # Chứa ~50 ảnh thực tế của căn hộ, biệt thự, shophouse, văn phòng
├── banners/   # Chứa 10 ảnh banner nền khổ ngang chất lượng cao
└── avatars/   # Chứa ảnh đại diện của khách hàng, nhân viên tư vấn
```

## 📸 Chỉ dẫn tải ảnh mẫu chất lượng cao (50-100 ảnh)

Bạn có thể tải ảnh miễn phí bản quyền tại các trang web sau để đảm bảo giao diện đẹp nhất:
1. **Unsplash.com** (Tìm từ khóa: `luxury real estate`, `modern apartment`, `minimal home interior`, `office tower`).
2. **Pexels.com** (Tìm từ khóa: `luxury villa`, `penthouse view`, `shophouse design`).

*Lưu ý: Luôn đổi tên ảnh tương ứng với tên file trong file cấu hình seed JSON trước khi lưu.*
